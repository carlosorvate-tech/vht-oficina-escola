# ⚙️ Calculadora de Valor da Hora Técnica (VHT) - Oficina Mecânica

Plataforma educacional e comercial para cálculo de capacidade operacional, rateio de custos fixos e precificação de mão de obra (Mecânica Geral vs. Diagnóstico Eletrônico).

- **Propriedade Intelectual & Desenvolvimento:** INFINITUS SISTEMAS INTELIGENTES
- **Patrocínio Oficial & Fomento Educacional:** Auto Mecânica República
- **Tecnologia:** Python, Streamlit, Pandas

## Como executar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```
